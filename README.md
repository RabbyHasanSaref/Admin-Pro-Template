# Admin Pro - Admin Dashboard Template

A modern, clean and responsive Admin Dashboard Template built using basic HTML, CSS and Vanilla JavaScript.

## Project Information

- **Project Name:** Admin Pro
- **Project Type:** Admin Dashboard Template
- **Version:** 1.0.0
- **Frontend:** HTML, CSS, JavaScript
- **Architecture:** Multi-page Website

## Technologies Used

| Technology | Usage |
|---|---|
| HTML5 | Website structure and content |
| CSS3 | Styling, layout and responsive design |
| Vanilla JavaScript (ES6) | Interactions and functionality |
| Chart.js | Charts and data visualization |
| Font Awesome 6.7.2 | Icons |
| Google Fonts (Inter) | Typography |
| LocalStorage | Browser-side data storage |

## Main Features

- Responsive Admin Dashboard
- Sidebar Navigation
- Top Navbar
- Global Search UI
- Notification Panel
- Profile Navigation
- Dark / Light Mode
- Dashboard Statistics
- Revenue Chart
- Recent Activities
- Recent Users
- User Management
- Profile Management
- Application Settings
